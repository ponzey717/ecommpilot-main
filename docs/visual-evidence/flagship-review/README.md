# Flagship guide review captures

The six PNGs in this directory show the 2026-10-19 local article layout at 360, 390 and 1440 pixels for each flagship manuscript. They are design-review captures, **not published URLs**. A temporary local-only render was used to capture the pages; the committed guide status remains `review`, public routes return 404, and no Article schema or sitemap entry is emitted. The temporary render showed a publication-date line, which is preview scaffolding and not an editorial approval or live publication date.

The grey visual-evidence panels deliberately show that genuine redacted Seller Hub and AliExpress screenshots are still required. No marketplace screenshot or numeric research observation was fabricated.
